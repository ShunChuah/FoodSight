## Trigger functions

### restaurant_updated_at()

```sql
CREATE OR REPLACE FUNCTION public.restaurant_updated_at()
 RETURNS trigger
 LANGUAGE plpgsql
AS $function$
BEGIN
    IF (to_jsonb(NEW) - 'updated_at' - 'cluster_id')
       IS DISTINCT FROM (to_jsonb(OLD) - 'updated_at' - 'cluster_id') THEN
        NEW.updated_at := now();
    ELSE
        NEW.updated_at := OLD.updated_at;
    END IF;
    RETURN NEW;
END;
$function$
```
